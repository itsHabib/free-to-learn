# Qualification scope

The five terminal routes were exercised from fresh pinned local Git clones
using previously AI learner-authored implementations. This is source-aware
engineering/recovery evidence, not a new source-blind learner or human study.
The repository supplies starters/public checks; those private learner
implementations and their attempts are not included.

Debugger and Storage passed all seven public units, their original-program or
client/fault capstone assertions, documented export and recovered replay.
Runtime passed its pocket and trained checks, standalone learner capstone,
causal cache-isolation experiment and recovered replay. Adaptive passed ten
units, ten declared public variants, a 60-pair evaluation, checkpoint/resume and
fresh export/import checks; all original attempts remain preserved privately.
No live model provider was called. A recommendation to collect more evidence
is retained rather than forced to a positive policy-promotion decision.

Firmware's trust, inert-file capstone, expected policy/malformed rejections and
attempt-folder backup/recovery passed. Its unchanged core5/49/31/6 evidence is
inherited through exact terminal-code/fixture and learner-source parity, not a
new execution of that cleanup harness. This release covers the terminal route.
Optional browser reasoning/history/export remains unqualified; automatic file
download is unsupported, actual clipboard/file-save was not tested, and the
historical 28/30 journal is unchanged.

Observed tools were Node26.5.1 and Python3.14.6 on macOS arm64. Other/minimum
profiles retain their original course qualifications. A local clone verifies
exact Git transport/files and documented command behavior; it does not by
itself establish anonymous GitHub access, live website behavior, accessibility
or human learning. Human studies are not added as a mandatory release gate.
