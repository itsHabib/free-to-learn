# Free to Learn course projects

Source for Time-travel Debugger, Recoverable Storage, Small Language-model
Runtime, Firmware Forensics (terminal route), Adaptive Decision Engine, Inside
the Shot, Compiler and Optimizer, and Anti-cheat Engineering (beta).
Canonical development remains private; this learner snapshot has one clean
initial commit and contains no private development history.

```sh
git clone https://github.com/itsHabib/free-to-learn.git
cd free-to-learn
git rev-parse HEAD
```

Follow START-HERE.md for exact course directories and first commands. Source is
directly readable under courses/. Implement your own project; the TODO starters
are intentionally incomplete. Missing tools or import errors are setup failures.
No installation, account, API key, paid provider or private Ivy access is needed
when the documented Node/Python tools are already installed.

The .packages/ archives match the direct course files and support repeatable
validation/downloads. They contain no embedded Git history. Keep your actual
work, first failures, assistance and later revisions separately; never overwrite
your only export. Public worked/prerequisite support is labelled assistance.

Read QUALIFICATION.md for exactly what was exercised. Some course documents
retain historical build-status statements; they do not claim new human learning
or browser qualification. No private assessment, actual learner attempt, conversation, credential or user
record is included. Anti-cheat includes explicitly labelled public reference
policies/worked examples and grader controls already in its teaching package;
consulting them is assistance, not independent learner work.

Original code is MIT and original lesson prose/illustrations CC BY4.0, with Free
to Learn attribution. Third-party/model terms remain unchanged. Retain LICENSE.md,
LICENSE-SCOPE.json, LICENSES/, THIRD-PARTY-NOTICES.md and the course notices.
PUBLIC-SOURCE-MANIFEST.json pins the learner files. Production availability is
separate from this source snapshot; Free to Learn is https://freetolearn.world/.

[Changed-course CI coverage and limits](CI.md). Public setup/interface checks are distinct from full learner implementation or blind-trial evidence.
