# 2. Install a circuit without giving every relay the route

A running relay starts with an empty map. A circuit must exist before an encrypted request can be interpreted. In this lab, a trusted controller provisions it. This is an intentional simplification of key exchange, not a simulation of a Tor handshake.

Implement `createCircuit(path, control)` and `installCircuit(config, states)`. Use the exact object shapes in [the contract](../PROTOCOL.md). The imports in your starter include `randomUUID`, `freshSecret`, `importSecret` and `destroyKey`.

For each hop, generate two independent secrets and retain two client handles. Send only that hop's keys, previous ID and next ID. In path order, await installation before proceeding to the next hop. An `install` acknowledgment means the child has stored its local state; it does not establish trust in an independently operated relay.

The receiver must reject an existing circuit ID before mutating it. Its stored state contains imported handles and a new replay set, not raw setup secret strings. Different circuits on the same relay must have independent sets and keys.

**Predict before testing:** If installation at the second relay fails, is the first relay still holding keys? What if the second relay installed successfully but the acknowledgment was lost? Your rollback should attempt cleanup of every attempted installation, including the one whose result was uncertain. Preserve the original setup error.

```sh
node tools/check.mjs 2
node tools/lab.mjs interactive
```

In the interactive lab: `open alpha`, `view r1`, `view r2`, `view r3`, then `close alpha` and inspect again. Use your actual path if it differs. Record the ID, previous and next fields each relay receives. Explain why the whole controller trace reveals more than any one local state projection.

**Done when:** setup and rollback checks pass; each participating process stores a local circuit; close removes it; you can explain why storing every relay's secret at every hop would defeat the exercise.

If stuck: build a table with columns index, previous, relay, next. The first and last boundary values are `client` and `archive`. Track an attempted hop before awaiting its installation.
