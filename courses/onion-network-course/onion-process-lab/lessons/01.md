# 1. A relay becomes a process

In Circuit Observatory, a call into the next relay happened inside one process. Here a relay owns a separate heap and PID. The protocol is still yours, but an `await` can allow another request to arrive while the first one waits. A crashed process really loses its state.

Before code, draw five boxes: the client/controller and four relay processes. Connect three relays into one path. Mark which fourth relay could replace a failed member. Draw the trusted IPC setup channel separately from the simulated data links. The parent routes both, so it can observe the whole experiment.
