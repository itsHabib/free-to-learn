Primary technical accounts

Glenn Fiedler: What Every Programmer Needs To Know About Game Networking explains client/server state, prediction and correction. Use it to compare a client claim with server authority; its examples do not specify this course's tick or sequence contract.

Riot Games: Demolishing Wallhacks with VALORANT's Fog of War is a historical first-party account of reducing unnecessary state and handling visibility, performance and repair. Study architecture and evidence limits, without reproducing third-party attack tools or assuming its measurements apply here.

Node's performance API describes the clock used for the timing investigation and retention measurements. Its zero belongs to the current process; raw readings from different process lifetimes cannot establish elapsed time across a restart. Node's memory reporting distinguishes memory categories; serialized JSON bytes are a different measure.

Microsoft's debugging overview introduces user/kernel mode, symbols and host/target terminology for optional later native study. No driver installation or OS change belongs to this software core.

Optional book context

The local library registry verified these book identities from title/copyright metadata. Most remain bibliographic pointers. Two short sections of System Programming in Linux were additionally read: chapter 1 “Processes” and chapter 2 “System Calls.” They ground the distinction between stored program bytes, a running instance, and an OS interface; they do not validate this course’s Node runtime or provide its game rules. Full chapters were not reviewed.

  • Bruce Dang, Alexandre Gazet and Elias Bachaalany, Practical Reverse Engineering (2014): architecture and owned-native analysis context.
  • Dennis Andriesse, Practical Binary Analysis (2019): reasoning from an owned binary and reproducible observations.
  • Sy Brand, Building a Debugger (2025): debugger mechanisms after introductory use.
  • Stewart N. Weiss, System Programming in Linux: process and system-interface context. Local copyright says 2026; EPUB metadata says 2025.
  • Michael Hale Ligh and colleagues, The Art of Memory Forensics (2014): evidence interpretation, with historical tool limits.
