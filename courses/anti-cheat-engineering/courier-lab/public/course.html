A small systems starting point

A program is stored code; a process is one running instance. Here the browser and Node server run separately and exchange HTTP messages. The server keeps the authoritative score. A browser button can request an action, but changing browser memory cannot by itself change the server’s saved state. Trace that boundary before adding a guard.

The book context is System Programming in Linux, chapter 1, “Processes”; the networking reading and source limits are in the reading map. Node supplies the OS interfaces for this course, so native system-call programming is not a prerequisite.

What is outside this core?

Module 8 is an optional owned-native investigation with a separate platform bridge. It is not needed for this route. No third-party game tampering, kernel installation, OS-security change or production-security claim is part of these labs. Plan several sittings. The previous source-only estimate was 9–17 active hours for an experienced JavaScript engineer. The new guided work adds practice, so that range is a historical baseline, not an estimate for this version. Actual human duration and learning outcomes remain unmeasured.
