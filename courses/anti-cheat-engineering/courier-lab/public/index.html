02 / INSPECT THE BOUNDARY

A request is a proposal.

The courier can request a direction and an interaction. It cannot award itself points. Try a request containing a forged score.

Worked demonstration: this extra field is rejected by the message schema (the allowed field names and value types) and cannot change the score. The source lab below is your independent task.

LIVE HTTP

HTTP 200 / admitted means the input was staged. The next game tick decides whether an interaction succeeds; see the interaction decision below.

Connect to see a request and its result.

A cooldown is a waiting period after a successful interaction; another interaction cannot succeed until it ends.

Server authority
Movement, collision, range, cargo, cooldown and score.
Input lifetime
A direction lasts 4 ticks unless a newer input replaces it. Silence stops movement.
Sequence
A repeated or older sequence is a no-op. A retry alone is not a cheating finding.
Known limit
Legal automation can send the same messages as a human. This server does not prove a client is unmodified.

03 / BUILD THE DEFENSE

Restore a guard.
Prove it holds.

The complete reference is your comparison point. The first source lab removes one proximity check. You restore it, then prove remote pickup fails while a real delivery still succeeds.

  1. Establish the baselinenpm run ciStarts real server processes, sends legitimate and invalid traffic, and checks authoritative state.
  2. Open the source labnpm run lab:prepareCreates a private working copy with a missing guard. Follow lab/LEARNER.md, edit code and record your first attempt.
  3. Test catches and missesnpm run test:mutantsRemoves guards one at a time. Each negative control must fail at the intended state assertion.

What this proves

These tests can establish behavior for this protocol, seed and schedule. They cannot certify production anti-cheat, detect every modified client, or show that a learner can transfer the skill. Later lessons add telemetry evaluation, recovery, performance and owned-process integrity.
