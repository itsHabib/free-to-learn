## A call is a list of notes

A **note** is a start, a length, and two pitches: it slides from the first to the second. A gull's cry is a few long falling notes and then a run of short ones. Each call takes its pitch and its counts from a stream of random numbers `r`, like everything else in the world:

<!-- code-example {"file":"examples/sound.txt","region":"gullCall","language":"js","title":"gullCall, in the 8-sound (pure) region","change":"Write route: type the body in place of the throw line."} -->
```js {"file":"examples/sound.txt","region":"gullCall","title":"gullCall, in the 8-sound (pure) region","change":"Write route: type the body in place of the throw line."}
// A gull's cry as notes: [start, length, pitch at start, pitch at end] in
// seconds and hertz. A few long falling calls, then a run of short ones.
function gullCall(r) {
  const notes = [];
  const base = 1500 + r() * 700;
  let t = 0;
  for (let k = 0, long = 1 + ((r() * 3) | 0); k < long; k++) {
    notes.push([t, 0.32, base * 1.25, base * 0.8]);
    t += 0.45 + r() * 0.15;
  }
  for (let k = 0, short = 3 + ((r() * 5) | 0); k < short; k++) {
    notes.push([t, 0.11, base * 1.1, base * 0.92]);
    t += 0.17;
  }
  return notes;
}
```
<!-- /code-example -->

Every note starts where the last left off, plus a gap. `base` is one gull's pitch, and the ratios make a long note fall by a third and a short one by a sixth.

## From silence and back

A note sounds by an oscillator, a source that swings back and forth at the note's pitch. Left to itself it starts and stops at full swing, and a sound that starts in less than a couple of thousandths of a second is heard as a click. So each note gets an **envelope**: a level that rises from silence and falls back to it, drawn as points joined by straight lines:

<!-- code-example {"file":"examples/sound.txt","region":"callEnvelope","language":"js","title":"callEnvelope, in the 8-sound (pure) region","change":"Write route: type the body in place of the throw line."} -->
```js {"file":"examples/sound.txt","region":"callEnvelope","title":"callEnvelope, in the 8-sound (pure) region","change":"Write route: type the body in place of the throw line."}
// How loud a note of the call is, as points [seconds from its start, level]:
// from silence up to half in 0.03 seconds, then down to silence at the end. A
// note that started or stopped at full level would click.
function callEnvelope(len) {
  return [
    [0, 0],
    [0.03, 0.5],
    [len, 0],
  ];
}
```
<!-- /code-example -->

The page's `cry` turns the list into sound. It makes one oscillator with a sawtooth shape, sends it through a narrow filter that keeps the tones near 1.6 times the note's pitch, and drives a volume control (`g.gain`) with your points:

<!-- code-example {"file":"examples/sound.txt","region":"cry","language":"js","title":"cry, in the 8-sound (page) region","change":"Study: supplied. Not typed."} -->
```js {"file":"examples/sound.txt","region":"cry","title":"cry, in the 8-sound (page) region","change":"Study: supplied. Not typed."}
// One gull cry: a buzzy tone through a narrow filter, its pitch sliding down
// through each note.
function cry() {
  const C = audio.ctx;
  const t0 = C.currentTime + 0.05;
  const o = C.createOscillator();
  const g = C.createGain();
  const f = C.createBiquadFilter();
  o.type = 'sawtooth';
  f.type = 'bandpass';
  f.Q.value = 5;
  g.gain.value = 0;
  o.connect(f);
  f.connect(g);
  g.connect(audio.gulls);
  let end = t0;
  for (const [at, len, f0, f1] of gullCall(audio.rng)) {
    o.frequency.setValueAtTime(f0, t0 + at);
    o.frequency.exponentialRampToValueAtTime(f1, t0 + at + len);
    f.frequency.setValueAtTime(f0 * 1.6, t0 + at);
    const [[u0, first], ...rest] = callEnvelope(len);
    g.gain.setValueAtTime(first, t0 + at + u0);
    for (const [u, level] of rest)
      g.gain.linearRampToValueAtTime(level, t0 + at + u);
    end = t0 + at + len;
  }
  o.start(t0);
  o.stop(end + 0.1);
}
```

## Who is loud where

The last function decides how loud the surf, the wind, the crickets and the gulls are. The page sets four volume controls to its four numbers, each from 0 to 1:

<!-- code-example {"file":"examples/sound.txt","region":"soundMix","language":"js","title":"soundMix, in the 8-sound (pure) region","change":"Write route: type the body in place of the throw line."} -->
```js {"file":"examples/sound.txt","region":"soundMix","title":"soundMix, in the 8-sound (pure) region","change":"Write route: type the body in place of the throw line."}
// How loud each voice is, from where the listener is: [surf, wind, crickets,
// gulls], each 0..1. ground = land height under the camera, alt = camera height
// above it (or above the sea), speed in m/s.
function soundMix(ground, alt, speed, night, flockDist) {
  const sea = ground <= 0.5 ? 1 : 1 - smooth(0, 90, ground);
  return [
    (0.25 + 0.75 * sea) / (1 + alt / 45),
    clamp(0.12 + alt / 400 + speed / 60, 0, 1),
    (night * (ground > 1 ? 1 : 0.3)) / (1 + alt / 30),
    1 / (1 + flockDist / 160),
  ];
}
```
<!-- /code-example -->

`ground` is the land's height under you and `alt` is how far above it (or above the sea) the camera is. `smooth(0, 90, ground)` goes from 0 at the shore to 1 at 90 m, so the surf is at its loudest at the sea's edge. Dividing by `1 + alt / 45` halves it 45 m up. Wind rises with height and speed, crickets come out at night, and gulls fade as the flock gets far.

## Use it on a new case: the bell in the tower

In the village square stands a bell tower. Every hour it strikes as many times as the hour says, on a twelve-hour clock: once at one, twelve times at noon and at midnight. In `project/bell.js`, write `bellStrikes(hour)`, with `hour` a whole number from 0 (midnight) to 23, which returns the list of strikes, each `[seconds, hertz, level]`. It must:

- have as many strikes as the hour says, the first at 0 seconds;
- leave at least 1.2 s between strikes, so that the bell has time to swing;
- use one pitch, between 100 Hz and 900 Hz, and levels above 0 and up to 1;
- give the same strikes for the same hour, and the same for 3 and 15.

Write it yourself on every route; the bell's checks test it. Then open `world-08.html?seed=7&sound=bell` and touch the picture. The page works out the hour from your world's own sun, which hurries through noon, so the hour from noon to one o'clock lasts under 8 seconds; strikes wait for the ones before them. It adds two higher tones to your pitch to make a bell of it.
