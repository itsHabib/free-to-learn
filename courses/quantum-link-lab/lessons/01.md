```python {"file":"examples/scorer.py","region":"game","title":"Score the round","change":"Put this function in starter.py."}
def wins(x, y, a, b):
    need_different = x == 1 and y == 1
    return (a != b) == need_different
```
<!-- /code-example -->

The two comparisons produce booleans. On 11, both must be true. On any other input pair, both must be false to score a win.

## Where does 75% come from?

Give Alice two answers, one for each input. Do the same for Bob. Can all four input pairs win at once? To win on 00, Alice’s first answer must equal Bob’s first. To win on 01 it must also equal Bob’s second. Winning on 10 ties Alice’s second answer to Bob’s first. That leaves all four answers equal, but 11 requires different answers. Always answering zero wins three cases, so three out of four is achievable. When the four input pairs are equally likely, even randomly choosing a different rulebook each round cannot improve that average.

Use your own scorer to check every rulebook. Run `python3` in the course folder, then enter these lines. In the loop, `a[x]` and `b[y]` deliberately allow each player to see only their own input. Predict the largest score before printing it.

```python
from itertools import product
from starter import wins

cards = list(product((0, 1), repeat=2))
scores = [sum(wins(x, y, a[x], b[y]) for x, y in cards)
          for a in cards for b in cards]
print(max(scores), "of 4")
```

## Where do the quantum answers come from?

For a classical control, the boxes share a random bit and both report it for every input. This produces streams that look random on either side and match perfectly across the link. Look for `equal_probability` in `lab.py`. The quantum simulator prepares a pair known as a Bell pair. Each input now chooses the angle of a measurement. The chance the two bits match is `(1 + cos(angle difference)) / 2` for this pair in the chosen plane. For input 11 the angles are 135 degrees apart. A match becomes unlikely, exactly where the game rewards different answers.

Run both cases below. Before the second, predict the win rate when the visibility is zero. Visibility is the fraction of ideal pair signal in this simple mixture. The remaining fraction supplies independent random answers.

```sh
python3 lab.py simulate --model entangled --seed 7 --visibility 1
python3 lab.py simulate --model entangled --seed 7 --visibility 0
```

<details>
<summary>Check the prediction</summary>

Two independent fair bits match half the time and differ half the time. Either kind of round therefore has a 50% chance of winning when visibility is zero. Perfect visibility gives about 85.36% in expectation. A seeded run lets you compare the same experiment after a code change.

</details>

## Print an actual circuit

A circuit is a list of operations for a quantum processor. This command prints the circuit used for the 11 settings in the classroom model.

```sh
python3 examples/measurement.py 1 1
```

Read `h` then `cx`. The first puts the first qubit into an equal superposition of 0 and 1. The second flips its neighbor conditional on the first. Together these instructions prepare the pair. The two `ry` lines rotate the measurement axes before each qubit is read as a bit. Change the second argument to 0 and see which line changes. The output is OpenQASM 2 and can be imported into a compatible circuit tool. The local sampler calculates the outcome probabilities directly. The real Delft apparatus used electron spins and its own control hardware.
