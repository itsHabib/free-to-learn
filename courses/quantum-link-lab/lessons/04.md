## What the link promises

Imagine the caller hands Alice a qubit without telling her how it was prepared. Bob should end up with that same state. Alice and Bob first share a fresh entangled pair. Alice combines the caller’s qubit with her half, measures both, and sends the two resulting ordinary bits to Bob. Those measurements consume the input and the shared pair. Bob uses the bits as instructions for his half. Each of the four messages is equally likely for every input. The message alone gives him no description of the caller’s state. [Teleportation circuit and correction table](https://quantum.cloud.ibm.com/learning/en/courses/utility-scale-quantum-computing/teleportation)

A tester gets one privilege the receiver doesn't: it knows which state it prepared. It can choose a measurement that the correct state should pass with certainty. To test again it prepares a new qubit. The term **pass probability** below means the chance of recovering the expected measurement result. Percentages in the bench are calculated over the possible messages and measurements of an ideal circuit.

## Pick an input that sees the fault

Start with the familiar 0 and 1. Now try `plus`. The plus and minus states both yield a fair coin when measured as 0 or 1. They differ in **relative phase**: the two amplitudes that make up the qubit have the same sign in plus and opposite signs in minus. Those signs affect how amplitudes add when you change the measurement. Apply the gate called H just before reading a bit: plus becomes 0 and minus becomes 1. That gives you a way to tell them apart.

Write your prediction first. If Bob gets minus when the tester sends plus, what happens when the tester measures in that plus/minus basis? Run the full sweep to see which of the six probes expose the fault.

```sh
python3 teleport/bench.py sweep --receiver learner
```

The two other probes, `plus-i` and `minus-i`, put the second amplitude a quarter turn ahead or behind the first. They supply a third way to check the qubit. Covering all three axes matters when the software can mishandle phase.

## Trace one message

Keep the input fixed at plus. The left message bit requests a phase correction (Z). The right bit requests a flip (X). Compare the faulty receiver against a known-good one with the **same** measurement branch. A trace conditions on a possible message; on hardware you would have to collect many runs and group them afterward.

```sh
python3 teleport/bench.py trace --receiver learner --state plus --bits 10
python3 teleport/bench.py trace --receiver ideal --state plus --bits 10
```

<details>
<summary>Walk through message 10</summary>

On this branch Bob starts with minus. Message 10 requests Z only. Applying Z reverses the sign on the amplitude of 1, turning minus back into plus. Skip Z and the verifier reads the opposite outcome every time on this branch. There are four equally likely messages. Ignoring the phase bit spoils the two with a leading 1 for this probe, so the pooled result is 50%. For the state 1, Z changes only an overall sign; the verifier still sees 1 with certainty.

</details>

## Own the receiver

Open `teleport/receiver.py`. The supplied harness constructs and measures the circuit and sends your `corrections(phase, flip)` function the two classical bits. It expects a tuple of gate names in the order to apply them. Capture the failing check before editing.

```sh
python3 teleport/learner_checks.py
```

Keep the existing bit-flip behavior. Add the missing response to the phase bit. Try writing it from the trace, use the worked function below, or brief an agent with the two-bit contract. Record which route you used. Run the check again, then ask your receiver to handle all six preparations. Keep the faulty comparison available through `--receiver broken`.

```python {"file":"examples/recover.py","region":"receiver","title":"Turn two message bits into Bob’s corrections","change":"Replace corrections in teleport/receiver.py. Gates run from left to right."}
def corrections(phase, flip):
    gates = []
    if flip:
        gates.append("X")
    if phase:
        gates.append("Z")
    return tuple(gates)
```
<!-- /code-example -->

On 00 the tuple is empty. On 11 both operations are necessary for an unknown state. The protocol tells Bob what to do without exposing the private preparation label.

</details>

## Does anyone test a physical teleporter this way?

Pfaff and colleagues sent the same six kinds of input through a teleporter between distant qubits. They reported mean fidelity (agreement with the target state) of 0.50 ± 0.03 with the classical-message corrections turned off and 0.77 ± 0.03 with them enabled. Their disabled condition removes the entire correction. Our incident drops one correction and keeps the other. The published values come from their apparatus; the exact percentages above describe our simulator. [Experimental results, Fig. 4](https://qutech.nl/wp-content/uploads/2017/03/Unconditional-quantum-teleportation-between-distant-solid-state-quantum-bits.pdf)
