Quantum link lab

Can two boxes beat the rulebook?

Give Alice and Bob a box each. Each box sees its own input, 0 or 1, and gives one answer. They win if their answers match, except when both inputs are 1. Then they must disagree. The boxes can agree on rules before the game and cannot talk during it.

Why does the loss move?

A win on 00 ties Alice’s first answer to Bob’s first. A win on 01 ties it to Bob’s second answer too. Now a win on 10 forces Alice’s second answer to match all the others. That leaves 11 with identical answers when it needs different ones. Picking a random rulebook each round mixes strategies with the same ceiling. With independent, equally likely inputs, their best average is 75%.

Now try a pair of qubits.

A qubit is a physical system you can measure to get one bit. An entangled pair shares a state. Here the input selects how each box measures its half. Each answer on its own looks like a fair coin. Compare the answers afterward and a pattern appears: with the right measurement angles the pair wins about 85 times in 100 on average.

Your project is a Python tool that tells those cases apart. First you’ll score a round. Then you’ll try to fool your scorekeeper. Finally you’ll use it on measurements from two electron spins in labs 1.3 km apart.

Build your Bell-test reporter

You’ll need Python 3.10+ and enough Python to edit a function. On a computer, open a terminal in your Free to Learn clone and run the two commands below. The tap exercise and films work in this page.

cd courses/quantum-link-lab
python3 lab.py demo
  1. Score a single round. Write the win rule in your own reporter and catch the four-input bug.
  2. Break your metric. A box with a fixed answer scores 97%. Figure out how it did that.
  3. Inspect the Delft run. Combine four correlations, report uncertainty and diagnose a new dataset.
