A pass can coexist with a reason to hold

Compare two cases. In case A, a signed manifest binds a complete capture but the local config violates policy. In case B, config complies but the capture digest disagrees with the signed manifest. Both deserve a hold, for different reasons. The rule is to retain the independent evidence and name the failing requirement.

Run the Python inspection and the signature command on candidate. The first reports configuration findings; the signature gate can still pass. Neither tool subsumes the other. Record tool version, source hashes, input hashes and output filenames so another person can reproduce the two results.

A hold is a bounded recommendation for further classroom review, not an accusation. These fixtures are intentionally authored alternatives. An observation about verbose diagnostics cannot identify an attacker or prove malicious behavior.
