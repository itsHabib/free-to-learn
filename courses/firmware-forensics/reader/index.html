Firmware Forensics

A release arrives with a manifest and a claim that it is ready. Build the tools to say what the bytes support.

Original inert EDUFW1 containers. No real UEFI, execution, flashing or malware. The signature lab uses public test keys; it cannot authenticate a vendor.

Comfortable reading Python functions, dictionaries and byte arrays, and using a terminal. The trust-policy exercise uses one small JavaScript function. Python 3.10+ and Node 22+ must already be installed.

Choose a unit

Navigation stays open. Each unit has reading, recorded reasoning checks, terminal work and a fresh case. Allow roughly 20–60 minutes per unit, longer for implementation; these are planning estimates, not measured learner times.

UNIT 07
