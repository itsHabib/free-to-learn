Distinguish cause from observation

A digest difference is a byte observation. An intentional feature update is an explanation. The observation alone cannot identify intent. A release note, a validated build record or another independent source could support that explanation; repeated copies of the same note add little.

A physical reorder can change the whole-container digest while each component digest stays the same. That explains a packaging difference without inventing new component content. Conversely, a stable version number does not cancel an observed byte change.

In your report label each sentence observed, inferred or unknown. Include a concrete observation that would overturn an inference. You will reuse that discipline in the release investigation and the final logger case.
