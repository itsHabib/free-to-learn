My compiled-form investigation

Target identity

Copy the manifest and archive identity, platform and tools. State assistance.

First prediction and competing explanations

Link the saved record, chosen arguments, predictions, distinguishing probe and observations.

Correspondence map

For each semantic phase (input handling, base arithmetic, optional adjustments, final limit/return), give O0 address(es), O2 address(es), a numeric value trace, and the condition that makes the correspondence valid. Do not match by register name alone. Include one reused register with two different meanings and the actual instructions that establish each meaning.

Counterexample

State a plausible claim about source spelling, register meaning or branch count. Give concrete native inputs/results plus addresses from both builds that refute it. Explain what remains true despite the changed instruction shape.

Fresh prediction after feedback

Choose an unseen input outside the required probe table, with a different combination of signs/flags. Save prediction before running, then compare both results and explain any repair. Link separate prediction/result records.

Limits and handoff

Separate observed behavior, inferred behavior and source-spelling guesses. Name untested cases/platforms and assistance. Link original and revised model records and the exported/resumed folder. Test success is not map approval.
