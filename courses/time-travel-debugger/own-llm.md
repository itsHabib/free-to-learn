# Optional critique using your own LLM account

You can complete this course offline without a model. If you choose to ask one for feedback, review the export and select what you want to share through your own account. Nothing in this package uploads files, starts inference or sends messages. Do not share private data, credentials or third-party material you lack permission to send.

Copy the following prompt, the relevant public contract, the specific failing input and selected code/report. Describe assistance accurately in later attempts. A model's opinion does not replace deterministic results or certify mastery.

> Review this project against the attached public contract and report rubric. Separate observations supported by code or recorded output from hypotheses. Identify a concrete failing case, the expected behavior under the contract, and an experiment I can run locally. If evidence is insufficient, say what is missing. Ask for my prediction before revealing a project solution. Prefer a small diagnostic question or sibling example to a replacement implementation. Do not invent executed results, claim that a passing finite test proves correctness, or broaden the stated VM/persistence assumptions. Give advice I can test; keep your critique distinct from the course checker's verdict.

After critique, write your prediction, run the experiment and retain both first and revised attempts. State the model/account and scope of help if you used one. Model compliance with this prompt has not been tested.
