# Sources and boundaries

This course defines an original executable teaching model. Its primary local sources are contracts.md, the supplied runtime, the public behavioral cases and reference-produced examples.json. No purchased book source, exercise, quotation, diagram, paid service or external packet was used. The course is not an adaptation of a named book.

All numeric worked-example output in examples.json is generated by running the local author reference on original inputs. Public cases are finite requirements checks. Author verification records contain valid alternatives and deliberately broken implementations, and are excluded from the learner archive. Source-aware author testing is not an independent cold tryout or evidence of learning.

The tested environment is Node v26.5.1 on macOS. Other Node versions and operating systems remain unqualified. Minimum-runtime qualification, other operating systems, browser download identity, visual/accessibility acceptance, human duration and learning effectiveness remain unverified. No network call or inference is part of the learner's default route.
